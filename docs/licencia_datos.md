# Licencia del dataset origen

El dataset utilizado en este proyecto, **LinkedIn Job Postings 2023-2024** (Kaggle, usuario `arshkon`), se distribuye bajo licencia **Creative Commons Atribución-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)**.

Enlace a la licencia: https://creativecommons.org/licenses/by-sa/4.0/

Enlace al dataset original: https://www.kaggle.com/datasets/arshkon/linkedin-job-postings

## Qué implica esta licencia

- **Atribución:** se reconoce la autoría original del dataset (Kaggle, usuario arshkon) en la memoria del TFM y en este repositorio.
- **CompartirIgual:** cualquier material derivado de los datos que se comparta públicamente debe distribuirse bajo esta misma licencia.

## Nota sobre este repositorio

Este repositorio contiene únicamente **código** (consultas SQL, cuadernos de Python, dashboard) desarrollado a partir del dataset, no una copia del dataset en bruto ni de sus tablas procesadas. El dataset original debe descargarse directamente desde Kaggle siguiendo el enlace anterior.
